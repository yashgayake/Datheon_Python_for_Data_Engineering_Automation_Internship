## 📌 About the Project

This repository contains four Python task folders for practicing common data engineering and automation workflows. Each task is organized so it can be developed, executed, and documented independently.

> **Note:** Run and verify the scripts in your local environment before treating each task as complete. Sample datasets are for learning and demonstration.

## 🧩 Project Tasks

| Task | Project | Main Features | Technologies |
|---|---|---|---|
| **Task 1** | Paginated Web Scraper | HTML parsing, pagination, retry handling, CSV/JSON export, duplicate checks | Requests, BeautifulSoup |
| **Task 2** | Automated Data Cleaning | Missing-value checks, currency/date normalization, duplicate removal, schema validation | Pandas |
| **Task 3** | Database Auto-Ingestion & Upsert | SQLite table creation, primary keys, batch inserts, upsert logic, integrity checks | SQLite, Pandas, SQL |
| **Task 4** | Scheduled ETL Pipeline | Extract-transform-load workflow, execution logs, JSON run report, repeated scheduling | Python, Requests, Pandas, SQLite |

## 🛠️ Tech Stack

- **Language:** Python
- **Web scraping:** Requests, BeautifulSoup4
- **Data processing:** Pandas
- **Data formats:** CSV, JSON
- **Database:** SQLite
- **Automation and monitoring:** Python logging, scheduled execution
- **Version control:** Git and GitHub

## ⚙️ Setup

### 1. Clone the repository

```bash
git clone https://github.com/yashgayake/Datheon_Python_for_Data_Engineering_Automation_Internship.git
cd Datheon_Python_for_Data_Engineering_Automation_Internship
```

### 2. Create and activate a virtual environment

**Windows PowerShell**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use the environment's Python directly:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

## ▶️ How to Run

Run commands from the repository root. Some tasks depend on outputs generated by earlier tasks.

### Task 1 — Web Scraper

```bash
python main.py
python validate_data.py
```

### Task 2 — Data Cleaning

```bash
python task2/generate_dirty_data.py
python task2/clean_data.py
```

### Task 3 — Database Ingestion

```bash
python task3/db_loader.py
python task3/verify_db.py
```

### Task 4 — ETL Pipeline

```bash
python task4/pipeline.py
```

To start the repeating scheduler:

```bash
python task4/scheduler.py
```

Stop it with **Ctrl+C**. For a short test interval in PowerShell:

```powershell
$env:ETL_INTERVAL_SECONDS = "60"
python task4/scheduler.py
```

The scheduler keeps running until stopped.

## ⚠️ Notes & Limitations

- The scraper uses [Books to Scrape](https://books.toscrape.com/), a practice website for learning.
- Website structure, availability, and network access can affect results.
- Task 2 uses synthetic sales data, not real customer data.
- The ETL pipeline currently creates local logs and a JSON summary. Email or external alert delivery needs separate configuration.
- Do not commit `.venv/`, secrets, passwords, API keys, or private customer data.
- Only mark a task complete after running and verifying its scripts.
